## 如何开始使用设备

1. 在设备总览中找到目标设备，确认负责人、位置和仓库入口。
2. 进入设备仓库的“快速上手”，从硬件连接、开机与程序启动开始，完成第一个基础 Demo。
3. 按需查阅官方手册和实验室技术文档，再尝试其他典型 Demo。出现问题时先查看常见问题，仍无法解决则联系负责人或在设备仓库提交 Issue。

本仓库集中维护介绍与导航，具体安装命令、连接参数和操作步骤放在设备仓库中。
